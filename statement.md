# Problem Statement

 Most students have trouble remembering where their pocket money went by the end of the month. I built this Expense Tracker in Python to make that easier. You can note down your daily expenses, look them up later, and see simple reports, so it's easier to spend with a bit more control.

## What the project aims to do
- Save expenses in a plain text file so they're still there the next time you open the program (no JSON, no database).
- Let the user add, view, edit and delete expenses.
- Let the user search by category, month or keyword.
- Show the total spent, a category-wise breakdown and the highest expense.
- Let the user set a monthly budget and get a warning when they cross it.

## Concepts I used
This project uses what we learned in the first semester: variables, input and output, if-else, loops, functions, lists, dictionaries, string handling, file handling, exception handling and modules.
